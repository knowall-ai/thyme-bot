# Thyme Bot Icons

This folder needs two icon files for the Teams app manifest:

## Required Icons

### outline.png (32x32)
- Monochrome outline icon
- Used in Teams toolbar and app bar
- Should be transparent background with white/light colored outline
- Suggested: Simple herb/thyme leaf outline

### color.png (192x192)
- Full color icon
- Used in Teams app store and installation screens
- Should use KnowAll AI brand colors:
  - Primary green: #2E7D32
  - Background: white or transparent

## Brand Guidelines

- Use the Thyme/herb leaf motif
- Consistent with KnowAll.ai branding
- Clean, modern design

## Placeholder Generation

You can generate placeholder icons using tools like:
- https://placeholderlogo.com/
- Figma/Sketch with the Thyme brand assets
- Any image editor at the required dimensions

Replace this file with actual PNG icons before deployment.
